# Pareto34 v2 持仓改进：固定样本对照

## 结论

这次修复的是“把每日入场资格丢失当成必须清仓”的策略问题，不是定投，也不是保证跑赢长持。002371 在同一冻结行情、权息、全池前沿、费用和10%波动目标下，总收益从 **1.59%提高到49.13%**，建仓/退出各从284次降至17次。但最大回撤从10.23%升到11.84%，且仍远低于满仓长持基准。**未实现保本或普遍跑赢长持的目标。**

v1的34维原子、同日严格支配和建仓门禁不变。v2建仓还要求权息连续收盘不低于MA120；持仓连续3根收盘低于各自MA120才触发趋势退出。F1落选、RSI过热及OBV入场门禁失败不再单独清仓。账户回撤退出/冷静期、权息隔离、有效风险上限、次日开盘、T+1和截止退出不放宽。

建仓使用风险上限的90%，持仓超过新风险上限才调减到其90%；不因风险预算变大或价格回落自动补仓。10%缓冲是减少碎片交易的固定工程选择，MA120及3根确认也未做选优。整手、涨跌停、开盘跳空仍可能使实际仓位超过信号日上限。

## 口径

- 请求区间2016-09-10至2026-09-10，有效截止2026-09-08；每股独立100万元，13股共1300万元，闲置现金不计息。
- 从原3330只固定池按代码顺序等距取12只，再加入用户指定002371。并非随机样本、全市场结论或独立盲测；没有根据本轮结果反复调参。
- 全部版本使用同一已冻结全池F1，不用13只小池重算前沿。复用v1训练所选10%波动目标，未为v2重选风险参数。
- 长持对照使用同一现金/股份账本：首个有效收盘后的下一可成交开盘尝试一次满仓建仓，分红入现金、送转入股份，不再投入分红、不做趋势/风险退出，最后5个市场日按共同规则尝试清仓。未成交建仓可依据后续有效收盘重新尝试。
- 本对照不是旧Web“长线持有”页面的+1263.0%：日期、送转、现金分红及费用口径不同，不能把两者作为同一个基准。账本依然有权息到账日、红利税、涨跌停代理等既有近似。
- 本轮全部样本残值为零；费用已经扣除、现金分红已经入账，均不得重复加减。价差净贡献可按总盈亏减现金分红理解，不是逐笔价差百分比相加。

## 复现

Ubuntu01仓库根目录，使用独立虚拟环境；输出必须是不存在的新目录：

```bash
.venv/bin/python -B pareto_backtest.py \
  --compare-frozen output/pareto_mainboard_20260910 \
  --output output/pareto_trend_comparison_new \
  --codes 000001,000725,001379,002284,002371,002588,002916,600246,600655,601111,603135,603657,605599
```

入口只读冻结NPZ/JSON/前沿，不联网、不连接数据库、不改旧目录，不接受已存在的输出目录。逐股逐版本流水保留在本机独立输出目录；机器可读汇总及输入哈希随报告提交。未执行全市场新回测，默认历史总览仍显示v1冻结报告，当前网页明确标注旧收益/成交标记不属于v2。

[机器可读对比与29份输入哈希](comparison.json)保留全部39份账户摘要及年度数据。独立逐笔核验6445次成交的现金、股份、费用和分红；13份v1复放与原账户结果一致。测试及小样本核账不是全市场数据质量或盈利认证。

[最终验证记录](verification.json)：506项隔离测试通过，真实网络及非临时SQLite连接被阻断；首页320/390/768/1440/1920宽度无横向溢出。本轮没有真实单股行情刷新或全市场新回测。
