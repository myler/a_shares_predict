## 策略

### 融合策略

MACD核心(40%) + 多因子(30%) + 基本面(15%) + 量能(15%)，融合三类策略优势。

**评分公式：**

```
S = M × 0.40 + F × 0.30 + V × 0.15 + Q × 0.15
```

| 维度 | 权重 | 评分规则 |
|------|:--:|------|
| **M** (MACD核心) | 40% | 金叉+15/死叉−15 \| 零轴上+12/下−8 \| DIF↑₅+8/↓₅−5 \| BAR↑₃+5 \| 底背离₃₀+10 \| 顶背离₃₀−15 |
| **F** (多因子) | 30% | RSI[30,65]+10 / <30超卖+15 / >80超买−15 \| KDJ金叉+10/死叉−8 \| J<0+8 \| 布林下轨+12/上轨−8 \| WR>80+8 |
| **V** (基本面) | 15% | P₂₅₀<25%+20 / P₂₅₀<40%+10 / P₂₅₀>80%−15 \| YoY>20%+10 |
| **Q** (量能) | 15% | OBV₅>MA₂₀×1.08+12 / <0.92−12 \| 量价背离−18 |

**质量门禁（任一项触发即否决买入）：**

| 门禁 | 条件 |
|------|------|
| OBV背离 | OBV₅ / MA₂₀ < 0.90 |
| RSI超买 | RSI > 92 |
| 双弱信号 | M < 35 且 F < 40 |

**交易规则：**

| 方向 | 条件 |
|:--:|------|
| 🟢 买入 | S ≥ 65 ∧ 通过门禁 |
| 🔴 卖出 | 止损−8% \| 止盈+25% \| S<35 \| 获利回吐(S<50且盈利>12%) \| 顶背离 \| M顶/头肩顶破颈线 |

**经典形态（回测卖出专用）：**

| 形态 | 已破颈线 |
|------|:--:|
| 双头(M顶) | 强制卖出 |
| 头肩顶 | 强制卖出 |
| 看跌吞没 | 强制卖出 |

**批量回测结果 (99只)：**

| 板块 | 数量 | 🟢买入 | 均胜率 | 均收益 |
|------|:--:|:--:|:--:|:--:|
| 芯片 | 39 | 22 | 46.3% | +116.2% |
| 资源 | 30 | 7 | 47.8% | +108.8% |
| 消费 | 30 | 22 | 41.9% | +27.4% |
| **总计** | **99** | **51** | **45.0%** | **+84.2%** |

### 长线持有策略

买入持有不动，展示价差收益、累计分红、股息率走势。

- **买入**：数据起始日一次性买入
- **卖出**：不卖出，持有至今
- **分红**：持有期间所有已实施分红累加

## 分红回测

自动拉取 A 股历史分红数据（送股、转增、派息），计算每笔交易持股期间到手的每股分红金额。

- 数据源：新浪财经 F10
- 回测交易表显示每笔交易的价差收益 + 分红收益（元/股）
- 分红历史表展示历年派息方案与股息率

## 本地缓存

首次查询某只股票时从网络拉取全量数据并存入 SQLite，之后秒读。

- 数据库：`stock_cache.db`（已加入 .gitignore）
- K 线和分红数据均缓存

## 测试

```bash

```

覆盖 engine（MACD/背离/回测/预测/多因子）、fetcher（分红计算/边界条件）、db（缓存增删改查），共43个测试用例。


## Web 界面

```bash
./web.py 8099
```

浏览器打开 `http://localhost:8099`：

- 输入6位股票代码
- 选择策略：融合策略 / 长线持有
- 勾选"已持仓"后可选择"计算分红"
- 融合策略显示：四维评分卡 + 详细分析过程 + 门禁检查 + 三面板图表(价格/MACD/OBV)
