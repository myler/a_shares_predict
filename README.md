MACD择时 + 多因子共振 + **综合策略（三面量化）** + 长线持有，含分红回测、SQLite本地缓存、Web界面。

## 策略

### MACD择时策略

基于 MACD(12,26,9) 三维分析，牛市追涨、熊市空仓，背离信号触发买卖。

- **买入**：底背离（熊市抄底）| 零轴上金叉（牛市追涨）
- **卖出**：顶背离（牛市见顶）| 死叉（熊市止损）
- **牛熊判定**：价格 > MA60 且 MA60(10日斜率)↑ → 牛市，连续5日确认
- **评分**：金叉+2/死叉-2 | 零轴上+1/零轴下-1 | 牛+2/熊-2 | DIF↑+1/DIF↓-1 | 顶背离-3

### 多因子共振策略

激进短线策略，综合 RSI + KDJ + 布林带 + 威廉指标 + 量能确认，无冷却期，信号更频繁。

- **指标**：RSI(14) + KDJ(9,3,3) + Bollinger(20,2) + WR(10) + MA20
- **买入**：score≥2 且 RSI<75（不在超买区）
- **卖出**：score≤-3（强空信号）| 获利>8%回吐 | 止损-6% | 止盈+15%
- **评分**：RSI超卖+3/超买-3 | KDJ金叉+3/死叉-3 | J值<0+2/>100-2 | Bollinger下轨+2/上轨-1 | WR>85+2/<15-2 | MA20趋势±1

### 综合策略（三面量化）🆕

量化实现三合资本四阶段分析框架，三面独立评分 + 加权综合 + 质量门禁 + 冲突裁决。

| 阶段 | 内容 |
|------|------|
| Phase 1 | K线/指标/形态/OBV 同源采集 |
| Phase 2 | 三面独立评分 |
| Phase 3 | 质量门禁：OBV背离否决 \| RSI>95降级 \| 双维度<55降级 |
| Phase 4 | 冲突裁决：博弈 > 技术 > 基本面 |

**三面权重与子维度：**

| 面 | 权重 | 子维度 |
|------|:--:|------|
| 技术面 | 30% | 趋势(MA排列+MACD) / 动量(RSI+KDJ+WR) / 量能(量比+OBV+换手) / 通道(布林+ATR) / 形态(M顶+头肩顶+晨星+三白兵) / 筹码 |
| 博弈面 | 45% | OBV背离 / 量价关系 / 资金趋势代理 / 事件驱动(波动率) |
| 基本面 | 25% | 估值位置(250日百分位) / 增长趋势(年涨幅) / 盈利质量(季度涨跌+正日比) |

**交易规则：**
- 买入：综合≥65 + 通过门禁 + RSI<85
- 卖出：止损-8% | 止盈+20% | 综合<35 | 获利回吐(盈利>10%且综合<45)

**经典形态检测：**

| 形态 | 已破颈线 | 未破颈线 |
|------|:--:|:--:|
| 双头(M顶) | -25 | -15 |
| 头肩顶 | -30 | -20 |
| 三白兵 | — | +15 |
| 晨星 | — | +15 |
| 看跌吞没 | — | -15 |

### 长线持有策略

买入持有不动，展示价差收益、累计分红、股息率走势。适合与其他策略对比。

- **买入**：数据起始日一次性买入
- **卖出**：不卖出，持有至今
- **分红**：持有期间所有已实施分红累加
- **对比**：可直观看到"择时交易 vs 买入不动"的收益差异

## 分红回测

自动拉取 A 股历史分红数据（送股、转增、派息），计算每笔交易持股期间到手的每股分红金额。

- 数据源：新浪财经 F10
- 回测交易表显示每笔交易的价差收益 + 分红收益（元/股）
- 分红历史表展示历年派息方案与股息率

## 本地缓存

首次查询某只股票时从网络拉取全量数据并存入 SQLite，之后秒读。

- 数据库：`stock_cache.db`（已加入 .gitignore）
- K 线和分红数据均缓存，搜过的股票不用再等网络

## 测试


覆盖 engine（MACD/背离/回测/预测/多因子）、fetcher（分红计算/边界条件）、db（缓存增删改查），共43个测试用例。每次改代码后跑一次。

```bash

./run_cli.py predict 000651      # 仅预测
./run_cli.py help                # 帮助
```

## Web 界面

```bash
./web.py 8099                # 默认端口 8080
```

浏览器打开 `http://localhost:8099`：

- 输入6位股票代码
- 选择策略：综合策略（三面量化）/ MACD择时 / 多因子共振 / 长线持有
- 勾选"已持仓"后可选择"计算分红"
- 长线持有策略自动锁定已持仓
- 综合策略显示三面评分卡 + 质量门禁 + 经典形态 + 三面板图表(价格/MACD/OBV)
