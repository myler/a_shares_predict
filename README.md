## 策略

### 融合策略

MACD核心(40%) + 多因子(30%) + 价格位置/趋势(15%) + 量能(15%)。

**评分公式：**

```
S = M × 0.40 + F × 0.30 + P × 0.15 + Q × 0.15
```

| 维度 | 权重 | 评分规则 |
|------|:--:|------|
| **M** (MACD核心) | 40% | DIF/DEA 多空状态 \| 零轴位置 \| DIF↑₅/↓₅ \| BAR↑₃ \| 前高/前低动能背离 |
| **F** (多因子) | 30% | RSI[30,65]+10 / <30超卖+15 / >80超买−15 \| KDJ 多空状态 \| J<0+8 \| 布林下轨+12/上轨−8 \| WR>80+8 |
| **P** (价格位置/趋势) | 15% | P₂₅₀<25%+20 / P₂₅₀<40%+10 / P₂₅₀>80%−15 \| 年价格涨幅强弱；不代表财务基本面 |
| **Q** (量能) | 15% | OBV 5日净量能流 >40% +12 / <-40% −12 \| 量价背离−18 \| 年化波动率代理 |

**质量门禁（任一项触发即否决买入）：**

| 门禁 | 条件 |
|------|------|
| OBV净量能流 | 5日净量能流 < −60% |
| RSI超买 | RSI > 92 |
| 双弱信号 | M < 35 且 F < 40 |

**交易规则：**

| 方向 | 条件 |
|:--:|------|
| 🟢 买入 | 收盘满足 S ≥ 69 且通过门禁，下一交易日开盘执行 |
| 🔴 卖出 | 止损−12% \| 止盈+15% \| S<35 \| 获利回吐(S<50且盈利>12%) \| 顶背离 \| M顶/头肩顶破颈线 |

回测按买入佣金 $0.03\%$、卖出佣金 $0.03\%$、卖出印花税 $0.05\%$ 计算；总收益为顺序全仓交易的复利收益。

**经典形态（回测卖出专用）：**

| 形态 | 已破颈线 |
|------|:--:|
| 双头(M顶) | 强制卖出 |
| 头肩顶 | 强制卖出 |
| 看跌吞没 | 强制卖出 |

**批量回测结果（旧版 v2，固定 100 只缓存股票，2026-07-19）：**

| 板块 | 数量 | 🟢买入 | 均胜率 | 均价差复利（不含分红） |
|------|:--:|:--:|:--:|:--:|
| 芯片 | 39 | 15 | 46.0% | +158.9% |
| 资源 | 30 | 11 | 48.8% | +68.9% |
| 消费 | 30 | 18 | 47.9% | -5.1% |
| 金融 | 1 | 1 | 52.5% | +2.5% |
| **总计** | **100** | **45** | **47.5%** | **+81.1%** |

均胜率为各股票胜率的等权平均；均价差复利为各股票顺序复利收益的等权平均，不含分红。该口径较旧版 99 只样本的 45.0% 均胜率提高 2.5 个百分点。

### 沪深主板全量基线

`mainboard_baseline.py` 冻结当前沪深主板股票池（`600/601/603/605` 与 `000/001/002/003`），并要求东财返回有效正现价以排除退市历史代码。2026-07-19 冻结池为 3,189 只：沪市 1,698 只、深市 1,491 只。worker 为每只股票严格刷新不复权 K 线、运行融合策略回测，并把任务状态和摘要写入 `stock_cache.db`。

```bash
# 首次只冻结股票池；之后可安全重复执行
python3 mainboard_baseline.py --init-only

# 持续处理待处理与失败重试池，直到失败池为 0
python3 mainboard_baseline.py --until-complete --request-delay 0.3

# 查看成功/失败/待处理进度与失败样本
python3 mainboard_baseline.py --status --show-failed 20

# 只读本地 SQLite 缓存重放已完成基线；锁定冻结日期，不联网、不写回历史摘要
python3 mainboard_baseline.py --replay-cached
```

数据库中的 `baseline_runs` 保存冻结日期、策略版本和聚合指标；`baseline_jobs` 保存每只股票的状态、尝试次数、错误、K 线区间、交易数、胜率、价差复利和当前评分。`failed` 项会指数退避重试；连续 12 次无法取得任何数据的代码归档为 `fetch_failed` 排除项。日线少于 300 根或最后日线距冻结日超过 60 天的股票也会作为已处理排除项，不进入可比收益均值。全量基线为含费用的价差复利基线，不批量抓取分红，以避免把网络分红缺失混入策略比较。

`--repair-success-metrics` 只允许写回与当前策略版本相同的运行；对历史版本的参数比较请使用只读的 `--replay-cached`，它会保留来源策略版本并锁定冻结日期。

**已完成基线（2026-07-19）**：运行 ID `cn_sh_sz_mainboard_20260719_20260719T165921Z`，活动主板池 3,189 只，完成 3,189 只，其中可比较样本 3,146 只、历史不足排除 43 只、失败池 0 只。可比较样本的等权平均胜率为 45.42%，等权平均价差复利为 -13.08%；全交易胜率为 45.57%（124,883 / 274,053）。这是未来策略优化的固定对照，不应与跨股票资金组合收益混为一谈。

**v3 本地缓存重放（2026-07-20）**：在同一 `3,146` 只可比较样本、同一不复权日线和费用口径下，以 `S >= 69` 入场、`-12%` 止损、`+15%` 止盈重放，等权平均胜率为 `52.45%`，等权平均价差复利为 `-1.20%`，全交易胜率为 `52.59%`（`120,678 / 229,451`）。本机完整重放耗时 `13.57` 分钟，直接读取约 `706 万` 根 SQLite 缓存日线；重放会锁定运行的冻结日期，不读取之后新增的缓存日线，也不会联网。该参数是在这份历史样本上筛选得到，属于样本内验证，不构成未来表现保证。

### 长线持有策略

买入持有不动，展示价差收益、累计分红、股息率走势。

- **买入**：数据起始日一次性买入
- **卖出**：不卖出，持有至今
- **分红**：持有期间所有已实施分红累加

## 分红回测

自动拉取 A 股历史分红数据（送股、转增、派息），计算每笔交易持股期间到手的每股分红金额。

- 数据源：新浪财经 F10
- 回测交易表显示每笔交易的价差收益 + 分红收益（元/股）
- 分红历史表展示历年派息方案与股息率

## 本地缓存

首次查询某只股票时从网络拉取全量数据并存入 SQLite，之后秒读。

- 数据库：`stock_cache.db`（本地缓存，已由 `.gitignore` 排除，不纳入版本管理）
- K 线、分红、冻结股票池与基线结果均缓存
- 所有新拉取 K 线均为不复权口径，现金分红与送转单独计入。若某只股票的缓存来自旧版前复权后备源，请删除该股票的旧缓存后重新拉取。

```bash

```

- 输入6位股票代码
