## 策略

### 融合策略

MACD核心(40%) + 多因子(30%) + 价格位置/趋势(15%) + 量能(15%)。

当前 Web 端、预测与回测共用同一套融合评分引擎。信号在当日收盘后计算，订单一律在下一交易日开盘执行；因此不会用当日收盘价成交，也不会把尚未发生的数据用于当日信号。

**评分公式：**

```
S = M × 0.40 + F × 0.30 + P × 0.15 + Q × 0.15
```

18 项辅助指标的共识度为 $A_t \in [-100,100]$，当前交易使用的有效评分为：

$$
A_t = \frac{N_t^{+} - N_t^{-}}{18} \times 100
$$

$$
S_t^\ast = S_t - 0.08A_t
$$

其中 $N_t^{+}$、$N_t^{-}$ 分别是当日看多与看空的辅助指标数量。四维基础分为 $S_t$；辅助共识偏空时 $A_t<0$，会小幅提高有效评分，偏多时则小幅降低有效评分。$A_t$ 的范围使修正项最大为 $\pm8$ 分。

**计算前提：**

- 输入为按交易日升序排列的不复权 OHLCV 日线；至少需要 60 根日线才生成融合信号。
- `DIF = EMA(12) − EMA(26)`，`DEA = EMA(9, DIF)`，`BAR = 2 × (DIF − DEA)`。
- `P250 = (收盘价 − 250日最低收盘价) / (250日最高收盘价 − 250日最低收盘价)`；年价格涨幅为当前收盘相对 250 个交易日前收盘的变化。
- OBV 在收盘上涨日加成交量、下跌日减成交量、平盘日不变。5 日净量能流为 5 日 OBV 变化除以该窗口成交量之和。
- 当 250 日价格位置或年价格涨幅的数据不足时，P 维度保持基准分；这不会阻止其他维度继续计算。

| 维度 | 权重 | 评分规则 |
|------|:--:|------|
| **M** (MACD核心) | 40% | DIF/DEA 多空状态 \| 零轴位置 \| DIF↑₅/↓₅ \| BAR↑₃ \| 前高/前低动能背离 |
| **F** (多因子) | 30% | RSI[30,65]+10 / <30超卖+15 / >80超买−15 \| KDJ 多空状态 \| J<0+8 \| 布林下轨+12/上轨−8 \| WR>80+8 |
| **P** (价格位置/趋势) | 15% | P₂₅₀<25%+20 / P₂₅₀<40%+10 / P₂₅₀>80%−15 \| 年价格涨幅强弱；不代表财务基本面 |
| **Q** (量能) | 15% | OBV 5日净量能流 >40% +12 / <-40% −12 \| 量价背离−18 \| 年化波动率代理 |

#### 完整评分规则

每个维度以 `50` 分起算，按下列规则加减分；总分不额外裁剪，直接按 $S = 0.40M + 0.30F + 0.15P + 0.15Q$ 加权。这样低分与高分都会保留，而不是被强行压进固定区间。

**M：MACD 核心，权重 40%**

| 条件 | 调整 |
|------|:--:|
| DIF > DEA / DIF ≤ DEA | +15 / −15 |
| DIF 在零轴上 / 零轴下 | +12 / −8 |
| DIF 5 日斜率为正 / 非正 | +8 / −5 |
| BAR 较 3 日前上升 | +5 |
| 30 日窗口出现前低后动能修复：价格离前低超过 3%，且 DIF 高于前低时 | +10 |
| 30 日窗口出现高位动能转弱：价格接近前高 2% 内，且 DIF 低于前高时的 90% | −15 |

**F：多因子确认，权重 30%**

| 指标 | 条件与调整 |
|------|------|
| RSI(14) | 30–65：+10；<30：+15；>70：−8；>80：−15 |
| KDJ(9,3,3) | K>D：+10；K<D：−8；J<0：+8；J>100：−8 |
| Bollinger(20,2) | 收盘位于带宽 <10%：+12；>90%：−8 |
| WR(10) | >80：+8；<20：−8 |

**P：价格位置与趋势，权重 15%**

| 条件 | 调整 |
|------|:--:|
| 250 日区间位置 <25% / <40% / >80% | +20 / +10 / −15 |
| 250 日价格涨幅 >20% / <−20% | +10 / −10 |

这里的 `P` 只描述价格位置和价格趋势，不含财务报表、PE、ROE 等真实基本面数据。

**Q：量能与量价关系，权重 15%**

| 条件 | 调整 |
|------|:--:|
| OBV 5 日净量能流 >40% / <−40% | +12 / −12 |
| 5 日价格上涨且 OBV 净流 <−20% | −18 |
| 5 日价格下跌且 OBV 净流 >20% | +12 |
| 5 日跌幅 >3%、60 日年化波动率 <25% | +10，低波下跌的机构吸筹代理 |
| 20 日跌幅 >10%、60 日年化波动率 <25% | +15，强吸筹代理 |
| 5 日跌幅 >3%、60 日年化波动率 >40% | −8，高波恐慌代理 |

机构代理按上表顺序匹配，命中第一项后不再叠加后续机构代理调整。

**质量门禁（任一项触发即否决买入）：**

| 门禁 | 条件 |
|------|------|
| OBV净量能流 | 5日净量能流 < −60% |
| RSI超买 | RSI > 92 |
| 双弱信号 | M < 35 且 F < 40 |

#### 交易与执行规则

| 方向 | 条件 |
|:--:|------|
| 🟢 买入 | 收盘满足 $S_t^\ast \ge 69$ 且通过门禁，下一交易日开盘执行 |
| 🔴 卖出 | 止损−12% \| 止盈+15% \| $S_t^\ast<35$ \| 获利回吐($S_t^\ast<50$ 且盈利>12%) \| 顶背离 \| M顶/头肩顶破颈线 |

卖出信号同样在收盘形成、下一交易日开盘执行。止损、止盈与获利回吐判断使用已计入交易成本的浮动价差收益：买入佣金 $0.03\%$、卖出佣金 $0.03\%$、卖出印花税 $0.05\%$。持仓超过 10 个交易日后，每 5 日额外检查一次 M 顶破颈线、头肩顶破颈线和看跌吞没；顶部动能背离会立即触发卖出。回测只统计已完成的交易，末尾尚未触发卖出的持仓不强制平仓。

**预测信号映射：**

| 前提 | 综合分 | 未持仓建议 | 已持仓建议 |
|------|:--:|------|------|
| 通过门禁 | $S_t^\ast \ge 70$ | 买入 | 增持 |
| 通过门禁 | $69 \le S_t^\ast < 70$ | 买入 | 拿住 |
| 通过门禁 | $50 \le S_t^\ast < 69$ | 观望 | 减持 |
| 通过门禁 | $40 \le S_t^\ast < 50$ | 不买 | 减持 |
| 通过门禁 | $S_t^\ast < 40$ | 不买 | 卖出 |
| 任一门禁否决 | 任意 | 观望 | 观望 |

#### 辅助指标投票面板（18 项）

辅助指标投票面板仍然保留，并在 Web 结果中显示每项的数值、看多/看空/中性结论以及整体共识。它不改变三项门禁，也不会单独触发买入或卖出；但共识度 $A_t$ 会按 $S_t^\ast=S_t-0.08A_t$ 对有效评分做小幅反向修正。

每项指标投 `+1`（看多）、`0`（中性）或 `−1`（看空）。当至少一项指标非中性时：

$$
	ext{看多占比} = \frac{N_t^{+}}{N_t^{+} + N_t^{-}} \times 100
$$

若全部中性，则共识度为 `0`、看多占比为 `50%`。少于 60 根日线时，18 项均标为数据不足/中性。

| 指标 | 看多票 `+1` | 看空票 `−1` |
|------|------------|------------|
| DMI | PDI > MDI 且 ADX > 20 | MDI > PDI 且 ADX > 20 |
| CCI | < −100 | > 100 |
| BIAS(6) | < −3% | > 5% |
| BIAS(12) | < −5% | > 8% |
| EXPMA | EMA12 > EMA50 且收盘 > EMA12 | EMA12 < EMA50 且收盘 < EMA12 |
| BBI | 收盘 > BBI | 收盘 < BBI |
| TRIX | > 0.05 | < −0.05 |
| VR | < 70 | > 350 |
| BR | < 60 | > 300 |
| AR | < 60 | > 200 |
| CR | < 50 | > 300 |
| DMA | DMA > 0 且收盘 > MA10 | DMA < 0 且收盘 < MA20 |
| DPO | < 当前收盘价的 −5% | > 当前收盘价的 +5% |
| MTM | > 0 | < 0 |
| SKDJ | K < 20，或 K>D 且 K<50 | K > 80，或 K<D 且 K>50 |
| LWR | LWR1 > 80 且 LWR2 > 70 | LWR1 < 20 且 LWR2 < 30 |
| ENE | 通道位置 < 10% | 通道位置 > 90% |
| LON | 通道位置 < 20% | 通道位置 > 80% |

面板将短线超卖共识视作反向机会、将短线过热共识视作减分因素；自动执行仍严格服从有效评分 $S_t^\ast$、三项门禁和交易规则。

**形态与背离卖出细则：**

| 规则 | 触发条件 |
|------|------|
| 顶部动能背离 | 当前收盘位于近 30 日前高的 2% 内，且当前 DIF 低于前高 DIF 的 90% |
| M 顶破颈线 | 最近两个局部高点相差不足 5%、间隔至少 15 日，且收盘跌破两峰之间低点 |
| 头肩顶破颈线 | 最近三处局部高点中头部高于两肩、两肩差异不足 10%，且收盘跌破两谷低点 |
| 看跌吞没代理 | 两日前存在上涨，当前收盘低于昨日收盘 3% 以上，且低于两日前收盘 |

#### 策略边界

- 该策略只使用价格和成交量派生指标；`P` 不是财务基本面评分，机构吸筹/恐慌也是量价代理而非真实资金流。
- 策略计算使用当前与此前日线，不使用未来数据；真实交易仍可能受到滑点、涨跌停、停牌、流动性和实际成交约束影响。
- 分红和送转在持仓收益展示中单独处理，不与不复权价格信号混用。

**经典形态（回测卖出专用）：**

| 形态 | 已破颈线 |
|------|:--:|
| 双头(M顶) | 强制卖出 |
| 头肩顶 | 强制卖出 |
| 看跌吞没 | 强制卖出 |

### 长线持有策略

买入持有不动，展示价差收益、累计分红、股息率走势。

- **买入**：数据起始日一次性买入
- **卖出**：不卖出，持有至今
- **分红**：持有期间所有已实施分红累加

### 巴芒基本面研究

这是独立的非金融企业财务质量初筛，不是日线交易策略，也不参与融合策略的四维加权。

- **数据来源**：东方财富财务摘要中的已披露年报行；每项结果展示报告期和披露日。
- **初筛项目**：最近三年扣非归母净利润连续性、累计经营现金流/扣非利润、加权 ROE 中位数、最新资产负债率与流动比率、收入规模趋势。
- **研究状态**：`通过财务质量初筛`、`观察并补充核验`、`暂不进入价值候选池`、`数据不足`、`方法不适用`。
- **适用边界**：银行、保险、券商等金融机构触发“方法不适用”；少于三份年报时不作结论。
- **不做的事**：不以摘要数据代替原始年报、审计意见、治理与护城河审查；不输出 DCF 目标价，也不产生买卖信号。

它的用途是先判断一家公司是否值得进入长期研究候选池。后续若要作为融合策略的候选池门禁，必须使用披露日可得的历史财报做独立、滚动的样本外验证，不能直接把当前质量结论回填到历史回测。

## 横截面多因子海选与回测（研究工具）

与融合策略（单只股票四维评分）不同，这是一套**全市场横截面选股**工具：每个调仓日对全市场主板股票按多因子排序取 top-N。

### 因子与权重

`factors.py` 定义 12 个技术因子，权重由 60 日持仓 ICIR 归一化训练（2026-09 全量 3330 只主板）：

- **最强正因子**：低波动率(low_vol)、低ATR(atr_amp)、小市值/低成交额(liq_factor)
- **反向因子**（回避强势股）：动量(mom_60/mom_250)、多头排列(ma_align)、量价齐升(pv_corr)

### 回测结论

**纯横截面选股天花板 = 56.4%**（技术12 + 基本面4因子，top50，持有60日）。

A股 60 日尺度是「反转 + 低波 + 小市值」市场——reward 技术面被打压、低波动的股票；不 reward 基本面质量（毛利率/净利率/增速 IC 均≈0）、不 reward 财务估值便宜（E/P 证伪）、也不 reward 趋势动量。

三个"突破杠杆"均已回测证伪（不要重试）：

| 杠杆 | 结果 | 原因 |
|------|------|------|
| 市场择时（牛市才买）| 54.2%（空仓78%时间）| 追牛市与反转逻辑矛盾 |
| 止损止盈退出机制 | 50.0% | 反转股"先跌后大涨"被止损截断 |
| 价值因子 E/P | 52.7%（单独IC+0.03但组合降）| 60日尺度不 reward 便宜 |

### 集成 MACD 择时（突破 62%）

`factor_backtest5.py` 把横截面选股与个股级 MACD 择时集成：

**横截面 top200 候选池（买哪只）+ 个股 MACD 底背离（何时买）+ 超时强平60日（何时卖）= 62.1%**，基线纯 MACD 择时 58.9%（+3.2pp）。

三步贡献：横截面过滤 +1.4pp → 只保留底背离（去掉零轴上金叉）+0.3pp → 超时强平60日 +1.5pp。

关键发现：
- 零轴上金叉在横截面"弱股"池里是负信号（胜率57.6%、平均收益−0.28%），底背离（抄底）才与低波/反转契合
- 超时强平是决定性参数（参数扫描平滑单调，非单点过拟合）

⚠️ **样本内选参 + 分段衰减**：前半段 63.6%、后半段 60.7%，近年有效性下降；62.1% 是"贴线"突破，样本外可能更低。

## 分红收益计算

自动拉取 A 股历史分红数据（送股、转增、派息），计算每笔交易持股期间到手的每股分红金额。

- 数据源：新浪财经 F10
- 回测交易表显示每笔交易的价差收益 + 分红收益（元/股）
- 分红历史表展示历年派息方案与股息率

## 本地缓存

首次查询某只股票时从网络拉取全量数据并存入 SQLite，之后秒读。

- 数据库：`stock_cache.db`（本地缓存，已由 `.gitignore` 排除，不纳入版本管理）
- K 线、分红与本地任务状态均缓存
- 所有新拉取 K 线均为不复权口径，现金分红与送转单独计入。若某只股票的缓存来自旧版前复权后备源，请删除该股票的旧缓存后重新拉取。
